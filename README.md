# ОТУТТО — персональные контакты

Две статические страницы: `svetlana/` и `evgeniy/`.
На каждой странице: Позвонить → Telegram → WhatsApp → Сохранить контакт.
Контакты скачиваются в формате vCard 3.0 (UTF-8).
Telegram использует официальный формат `https://t.me/+номер`: переход к человеку зависит от настроек поиска по номеру в Telegram.

Публикация: GitHub Pages, ветка main, корневая папка. Файл .nojekyll отключает обработку Jekyll.
QR-коды должны вести на постоянные адреса опубликованных страниц.
